# V5.1 12M Curriculum Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a timed two-stage 12M humanizer candidate and a lineage-paired promotion evaluator without touching sealed data.

**Architecture:** `v5_1_model.py` owns the bundled 12M encoder, cross-window attention, FiLM fusion, and shallow head. `v5_1_train.py` owns balanced-base and curriculum training. `v5_1_compare.py` owns paired lineage bootstrap and promotion decisions. The notebook runs a timed first base epoch before completing the job.

**Tech Stack:** Python 3.13, PyTorch, NumPy, scikit-learn, pytest, Google Colab T4.

**Spec:** `docs/superpowers/specs/2026-09-05-v5-1-12m-curriculum-design.md`

## Global Constraints

- Read only `control-v1` train/development/calibration; never read GRADTEX, RAID, or any sealed cohort.
- Use lineage-group paired bootstrap for V5.1-vs-V4.8 comparisons.
- Train six balanced base epochs, then at most four H1-matched curriculum epochs; retain the balanced base as continuation epoch zero.
- Ties and inconclusive results are no-promotion outcomes; calibration is post-selection only.
